# Доказательство нерегулярности языка aⁿbⁿ

Рассмотрим язык `L₂ = { aⁿbⁿ | n ≥ 0 }` над алфавитом `{a, b}`. Докажем от противного, что он не является регулярным.

## Лемма о накачке для регулярных языков

Если язык регулярный, существует число `p ≥ 1` такое, что всякое слово `w` языка с длиной не меньше `p` можно записать как `w = xyz`, где:

1. `|xy| ≤ p`;
2. `|y| > 0`;
3. для каждого `i ≥ 0` слово `xyⁱz` также принадлежит языку.

## Применение к L₂

Предположим, что `L₂` регулярно, и возьмём слово `w = aᵖbᵖ`. Оно принадлежит `L₂` и имеет длину не меньше `p`.

Для любого разбиения `w = xyz`, удовлетворяющего первым двум условиям леммы, первые `p` символов слова — это `a`. Поэтому `x` и непустая часть `y` состоят только из `a`; пусть `y = aᵏ`, где `k ≥ 1`.

Накачаем слово вниз, взяв `i = 0`. Получим:

```text
xz = aᵖ⁻ᵏbᵖ
```

В нём меньше `a`, чем `b`, следовательно, `xz ∉ L₂`. Это противоречит третьему условию леммы. Значит, исходное предположение неверно и `L₂` нерегулярен.

## Связь с программой

Стековый алгоритм `automata/stack_checker.py` хранит число ещё не сопоставленных `a` и снимает по одному символу при чтении `b`. Для любой конечной длины он проверяет равенство количеств и правильный порядок. Конечные тесты демонстрируют работу реализации, но доказательство выше относится ко всему бесконечному языку.
