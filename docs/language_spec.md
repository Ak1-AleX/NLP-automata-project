# Формальная спецификация учебных языков

Документ задаёт точные языки, которые проверяют модули проекта. Он нужен, чтобы результат анализатора можно было трактовать как принадлежность формальной модели, а не как общую оценку естественного языка.

## 1. Регулярный язык L₁

`L₁ = { aᵐbⁿ | m, n ≥ 0 }`, алфавит `Σ₁ = {a, b}`. Эквивалентное регулярное выражение: `a*b*`. Пустая строка принадлежит языку. После первого `b` символ `a` уже не допускается.

ДКА реализован в `automata/dfa.py`:

| Состояние | `a` | `b` | Принимающее |
|---|---|---|---|
| `q0` | `q0` | `q1` | да |
| `q1` | `q2` | `q1` | да |
| `q2` | `q2` | `q2` | нет |

`q0` — начальное состояние, `q2` — ловушка. Любой символ вне `Σ₁` является ошибкой входа, а не обычным отклонением языка.

## 2. Нерегулярный язык L₂

`L₂ = { aⁿbⁿ | n ≥ 0 }`, алфавит `Σ₂ = {a, b}`. Между символами не допускаются пробелы. Строка состоит из некоторого числа `a`, затем из такого же числа `b`; пустая строка соответствует `n = 0`.

Модуль `automata/stack_checker.py` кладёт каждую `a` в стек, затем снимает по одному символу на каждую `b`. Принимает только если порядок не нарушен и стек пуст после чтения всей строки. Грамматика в `grammar/anbn.lark` задаёт те же строки правилом `S → aSb | ε` и не игнорирует пробелы.

## 3. Учебный фрагмент английского языка

Грамматика из `grammar/english.lark`:

```text
S   → NP IV
NP  → Det N
NP  → Det N that NP V
Det → the | a
N   → cat | dog | boy | girl | man | woman | bird | child
IV  → ran | slept | smiled | waited | laughed
V   → saw | chased | heard | found | liked
```

Глубина предложения — число рекурсивных применений правила `NP → Det N that NP V`. Например, `the cat ran` имеет глубину 0, а `the cat that the dog chased ran` — глубину 1.

Терминальные слова разделяются пробелами. Регистр значим, точка и другая пунктуация грамматикой не предусмотрены. Допускается любая глубина, которую может обработать доступная память и время выполнения парсера.

## 4. Ограниченная регулярная модель

`automata/bounded_nesting.py` строит регулярное выражение для предложений с глубиной не выше параметра `max_depth`. При каждом конечном значении лимита получается конечная регулярная модель; повышение лимита расширяет её покрытие. Для демонстрации берётся один и тот же набор предложений и сравнивается с рекурсивной CFG.

Модель не утверждает, что для всех структур естественного языка достаточно фиксированной глубины. Она описывает только указанный учебный язык до указанного лимита.

## 5. Контролируемо некорректные предложения

Генератор использует шесть преобразований корректного примера: нарушение порядка слов, удаление главного глагола, лишний артикль, незакрытое вложение, неизвестное слово и удаление артикля. Это отрицательные примеры относительно данной грамматики, а не экспертная разметка естественного английского.
