# Контракт анализаторов

Все функции `analyze()` в `automata/dfa.py`, `automata/stack_checker.py`, `automata/bounded_nesting.py` и `grammar/parser.py` возвращают словарь с одинаковым набором полей:

| Поле | Тип | Значение |
|---|---|---|
| `accepted` | `bool` | Принадлежит ли строка распознаваемому языку |
| `method` | `str` | `dfa`, `stack`, `bounded` или `cfg` |
| `input` | `str` | Исходная строка без преобразований |
| `tokens` | `list[str]` | Токены английской CFG; пустой список для символьных автоматов |
| `trace` | `list[dict]` | Переходы ДКА или шаги стека; пустой список у CFG и bounded-модели |
| `parse_tree` | `str | None` | Скобочная запись дерева CFG, если вход принят |
| `error` | `str | None` | Ошибка алфавита/разбора либо `None` для обычного принятия или отклонения |
| `elapsed_ms` | `float` | Замер времени вызова анализатора в миллисекундах |

`accepted = False` и `error = None` означает обычное отклонение по правилам языка. Для английских анализаторов неизвестное слово, а для символьных языков символ вне алфавита возвращают `error`; такой пример остаётся в общем числе отрицательных записей, но не засчитывается как корректное отклонение ни у одной модели. Классификация словаря общая для CFG и ограниченной регулярной модели. Исключение, возникшее внутри анализатора, также фиксируется как ошибка и не считается отклонением.

Успешное дерево CFG записывается S-выражением, например:

```text
(s (np (det the) (n cat)) (iv ran))
```

Узлы Lark `start` снимаются. Терминальные слова остаются в дереве благодаря `keep_all_tokens=True`.

## Формат трассировки ДКА

Каждый элемент содержит номер шага `step`, текущее состояние `state`, входной символ `symbol` и `next_state`. Нулевой элемент описывает начальное состояние и имеет `symbol = None`.

## Формат трассировки стека

Элемент содержит `step`, `symbol`, действие `push`, `pop` или `reject` и независимую копию стека после шага. При нарушении порядка трассировка останавливается на отклоняющем символе.

## Эксперимент

`evaluate(dataset, methods)` принимает общую выборку и список методов в виде `{"name": str, "fn": callable, "options": dict}`. Возвращает `summary` и записи `details`. `accuracy_by_depth` считается только по корректным примерам и означает их долю принятия; отклонение некорректных примеров приводится отдельными счётчиками.
