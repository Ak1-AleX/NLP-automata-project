# Где заканчиваются возможности конечного автомата?

Учебный проект на стыке обработки естественного языка (NLP) и математической логики и теории алгоритмов (МЛИТА). Программа сопоставляет конечный автомат, стековый алгоритм, регулярную модель с заданным пределом вложенности и рекурсивную контекстно-свободную грамматику.

Английская грамматика намеренно описывает небольшой формальный фрагмент. Она демонстрирует рекурсию и деревья разбора, но не предназначена для анализа всего английского языка.

## Возможности

- ДКА с трассировкой для регулярного языка `L₁ = {aᵐbⁿ | m, n ≥ 0}`.
- Стековая проверка языка `L₂ = {aⁿbⁿ | n ≥ 0}`.
- Рекурсивная грамматика Lark для вложенных английских придаточных.
- Регулярная модель, которая принимает предложения только до заданной глубины.
- Генерация корректных и контролируемо некорректных примеров, сравнение на общем наборе, график и экспорт CSV/JSON.
- Streamlit-интерфейс с диаграммой автомата, деревом разбора и таблицей работы стека.

## Установка

Требуется Python 3.10 или новее. Зависимости перечислены в `requirements.txt`.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Запуск интерфейса:

```powershell
python -m streamlit run app.py
```

Для построения диаграмм используется компонент Graphviz в Streamlit и Python-пакет `graphviz`. Устанавливать отдельный системный Graphviz для запуска приложения не требуется.

## Проверки и эксперимент

Запуск автоматических проверок:

```powershell
python -m pytest -q
```

Воспроизводимый эксперимент по умолчанию проверяет глубины 0–4, использует 20 корректных и 20 некорректных примеров на каждой глубине и seed 42. Регулярная модель ограничена глубиной 1.

```powershell
python -m experiments.run
```

Параметры можно менять:

```powershell
python -m experiments.run --max-depth 6 --n-per-depth 30 --bounded-depth 2 --seed 7
```

Команда сохраняет `summary.csv`, `details.json` и `metadata.json` в `experiments/results/`. В приложении результаты можно скачать без записи в каталог проекта.

## Структура

```text
automata/         ДКА, стековый анализатор и ограниченная регулярная модель
grammar/          Lark-грамматики и единый интерфейс CFG-анализатора
experiments/      Генератор, оценка моделей и CLI воспроизводимого прогона
visualization/    Диаграмма ДКА и преобразование дерева разбора в DOT
tests/            Автоматические проверки модулей и визуализаций
docs/             Спецификация, API, доказательство, отчёт и материалы презентации
app.py            Streamlit-интерфейс
```

## Как читать результаты

`accuracy_by_depth` показывает долю корректных (положительных) предложений, принятых на каждой глубине. В CSV отдельно приведены доли принятых корректных и отклонённых некорректных примеров. Общая точность в интерфейсе считает обе группы. Ошибки самого анализатора не считаются корректным отклонением.

Эксперимент на конечной выборке иллюстрирует работу конкретной реализации, но не доказывает нерегулярность языка. Формальное доказательство для `L₂` приведено в [`docs/pumping_lemma.md`](docs/pumping_lemma.md). Определения учебных языков и ограничения грамматики описаны в [`docs/language_spec.md`](docs/language_spec.md).
